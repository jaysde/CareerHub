# CareerHub

**Your AI mentor for lifelong learning.**

CareerHub is an AI-powered learning and mentorship platform concept designed to help people explore subjects, build skills, and move from curiosity toward real-world goals—all through a more focused learning journey.

## Vision

Learning can involve jumping between courses, videos, books, and websites without a clear plan. CareerHub aims to bring structure and guidance to that experience with a personalized AI mentor that helps learners decide what to learn, find useful resources, practice concepts, and keep progressing at their own pace.

CareerHub is designed to **complement educators, not replace them**.

## Planned Experience

- **Personalized learning paths** — learning plans shaped around a learner's goals, level, and pace.
- **Curated resources** — discover books, videos, and other learning materials.
- **Interactive practice** — quizzes, assignments, and exercises to reinforce understanding.
- **On-demand AI guidance** — ask questions and get help working through difficult concepts.
- **Career-focused growth** — connect learning with practical skills and real-world projects.

> These are the product vision and planned capabilities; not all features are implemented in the current website.

## Current Website

The current project is a responsive landing page built with:

- HTML5
- CSS3
- Vanilla JavaScript

It includes a hero section, feature cards, a learning-journey section, an overview of the product philosophy, responsive navigation, and a call-to-action placeholder. No frontend frameworks or external libraries are required.

## Run Locally

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the repository folder.
3. Open `index.html` in your browser.

You can also use a local development server in your editor if preferred.

## Deployment

The site can be hosted with GitHub Pages:

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.

If GitHub Pages is already enabled, push your changes to the configured branch to publish updates.
